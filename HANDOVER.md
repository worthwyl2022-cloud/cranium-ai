# Acquisition and IP handover notes

## Repository role

Supporting repository in the Convertible Cranium ecosystem.

This file is an operational handover aid. It does not establish legal ownership, assignment, inventorship, trademark rights, or third-party license compliance.

## Reproduction checklist

1. Clone the repository and check out the intended release commit.
2. Record runtime, package-manager, dependency, and tool versions.
3. Run the documented build, test, and verification commands.
4. Record expected outputs, known failures, external services, and required environment variables.
5. Do not place credentials, private keys, customer data, or confidential contracts in this repository.

## Transfer checklist

- [ ] Preserve the source commit and repository history.
- [ ] Identify canonical, supporting, historical, fixture, and generated material.
- [ ] Inventory third-party dependencies and assets.
- [ ] Confirm contributor and employer assignment status.
- [ ] Document deployment resources, domains, registries, and secrets outside the repository.
- [ ] Link this repository to the account-wide architecture and portfolio map.

Legal clearance remains a separate diligence workstream.
